# Freelance_dara_analysis

## 📌 Overview
This project explores a dataset of freelancer job postings.  
The dataset was provided as a ZIP file, which I extracted and analyzed in Google Colab.  
The goal was to uncover meaningful insights about salaries, skills, and job trends.

## ⚙️ Steps Taken
1. **Data Extraction**  
   - Unzipped the dataset and loaded it into Colab using Pandas.  

2. **Data Cleaning**  
   - Checked for missing values and duplicates.  
   - Standardized column names for easier analysis.  

3. **Exploratory Data Analysis (EDA)**  
   - Calculated basic statistics (mean, median, min/max).  
   - Grouped data by skills and categories.  
   - Visualized distributions using Matplotlib/Seaborn.  

4. **Insights**  
   - Identified which skills are most in demand.  
   - Highlighted salary ranges across different categories.  
   - Observed patterns in age and experience levels.  

## 📊 Key Findings
- Certain technical skills (like Python and Data Analysis) tend to have higher salaries.  
- Data entry and web scraping jobs dominate the dataset.  
- Younger freelancers (22–30) are active but often earn less compared to experienced ones.  

## 🛠 Tools Used
- Python (Pandas, Matplotlib, Seaborn)  
- Google Colab  
- Kaggle dataset  

## 🚀 How to Reproduce
1. Download the dataset from Kaggle.  
2. Upload it to Colab and extract the ZIP file.  
3. Run the notebook cells step by step.  
4. Visualizations and insights will be generated automatically.  

## 📄 Conclusion
This project demonstrates how to take a raw dataset, clean it, analyze it, and present findings in a clear way.  
It serves as a strong starting point for building a data science portfolio.
